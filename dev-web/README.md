# EveryDoing 로컬 브라우저 개발 모드

`cargo run --manifest-path src-tauri/Cargo.toml --bin dev_web`을 실행하고 터미널에 표시된 `http://127.0.0.1:포트/` 주소를 브라우저에서 연다. 서버를 종료하려면 터미널에서 Ctrl+C를 누른다.

기존 달력 화면과 실제 Rust 스캔을 사용한다. 첫 실행 시 데스크톱 앱의 폴더·확장자 설정을 참고하고 해당 설정에 맞는 기존 색인 캐시를 읽는다. 이후 브라우저 설정·메모는 `src-tauri/target/everydoing-web/`에 별도 저장된다. 드라이브 루트 MFT 재스캔은 관리자 권한이 필요하다.

폴더 추가는 전체 경로를 입력한다. 검색·달력·파일 열기·메모는 실제 동작한다. AI 요약은 이 개발 모드에서 지원하지 않으며, 데스크톱 앱에서 이용한다. 이 서버는 로컬 개발용이며 외부 배포용 서비스가 아니다.
