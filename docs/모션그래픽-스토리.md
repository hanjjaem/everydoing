# EveryDoing 모션그래픽 스토리

작성일: 2026-11-01  
상태: **핵심 메시지와 첫 장면 확정 · 세부 연출은 검토용 초안**

## 1. 영상이 전할 이야기

### 확정한 중심 문구

> **기억나지 않는 하루도, 다시 만날 수 있도록.**

### 핵심 약속

> **따로 기록하지 않아도, 작업한 파일이 하루의 기록이 됩니다.**

문서로 일하다 보면 분명 많은 일을 했는데 따로 기록하지 않아 무엇을 했는지 떠올리기 어려울 때가 있다. 그렇다고 바쁜 하루에 업무일지를 다시 쓰는 것 역시 또 하나의 일이다.

EveryDoing은 사용자가 선택한 폴더의 파일을 수정일 기준으로 달력에 보여주는 Windows 앱이다. **이미 작업한 파일을 단서로 한 일을 다시 떠올리고, 후속 처리처럼 놓친 일을 스스로 파악하도록 돕는다.**

### 시청자가 느끼면 좋은 것

- “오늘 뭘 했는지 떠올릴 때 도움이 되겠다.”
- “지난번에 어디까지 했는지, 자료를 언제 만들었는지 다시 찾아볼 수 있겠다.”
- “검토하고 나서 더 챙겨야 했던 일이 생각났다.”
- “보고나 실적 정리를 할 때 내 작업을 되짚을 수 있겠다.”
- “업무 기록을 내 PC에서 살펴볼 수 있겠다.”

**주요 시청자:** 문서와 파일로 일하지만, 자신이 한 일을 따로 기록할 여유는 없는 실무자. 특정 직업 하나에 한정하지 않는다.

## 2. 출발점: 공감할 수 있는 순간들

어느 하나만 정답으로 고르지 않는다. 다음은 같은 고민의 서로 다른 장면이다.

| 순간 | 머릿속 질문 | EveryDoing이 제공하는 실마리 |
| --- | --- | --- |
| 퇴근 전 | “오늘 무슨 일을 했더라?” | 오늘 수정된 파일을 날짜별로 살펴본다. |
| 월요일 아침 | “지난주에 어디까지 했지?” | 지난 날짜의 파일과 메모를 확인한다. |
| 업무 보고·성과 정리 | “이번 달에 어떤 일을 했지?” | 해당 기간의 파일을 보며 한 일을 되짚는다. |
| 자료 찾기 | “그 파일을 언제 만들었더라?” | 날짜와 파일명 검색을 단서로 찾아본다. |
| 인수인계·지난 업무 재개 | “그때 어떤 자료를 봤더라?” | 과거 날짜에 남은 파일들을 살펴본다. |
| 업무 자료 보관 | “내 업무 기록이 밖으로 나가는 건 아닐까?” | 색인과 메모는 로컬에 저장하고, AI 요약은 선택한다. |

영상에 이 모든 문장을 넣을 필요는 없다. **도입은 몇 가지 대표 질문으로 공감시키고**, 이후의 화면이 나머지 상황에도 적용될 수 있음을 보여준다.

## 3. 영상의 성격

- **분위기:** 차분하고 세련되게.
- **움직임:** 역동적으로. 흩어진 파일이 달력 속 각자의 날짜를 찾아가는 흐름이 중심이다.
- **시각적 변화:** 복잡하고 흩어진 상태에서, 날짜별로 정돈된 상태로 전환한다.
- **표현 원칙:** 빠른 움직임을 쓰더라도 화면을 읽을 시간을 확보하고, 무작위로 번쩍이거나 현란한 효과로 채우지 않는다.
- **화면 소재:** 기존 `docs/index.html`의 디자인과 화면을 출발점으로 삼는다. 제품 화면과 개념을 설명하기 위한 그래픽은 구분한다.
- **기본 형식 제안:** GitHub README에서 볼 가로형 영상과 자동 재생 미리보기. 정확한 길이, 음악·효과음·내레이션 사용 여부는 아직 미정이다.

## 4. 이야기 구조와 장면

아래 시간은 **약 22초 기준의 초안**이다. 읽기 속도와 장면 전환을 검토하며 조정할 수 있다.

### 장면 1 — 질문이 쌓인다 · 0–4초

**역할:** 다양한 사용 상황을 짧게 연결해 공감을 만든다.

**화면**  
업무 문서들이 하나둘 화면에 쌓인다. 질문이 서로 겹치지 않게 차례로 나타난다. 여러 장면은 빠르게 이어지지만, 문장을 읽을 수 있도록 간격을 둔다.

**확정한 화면 문구**

> 어제 뭐 했더라…?  
> 지난주엔 뭐 했더라…?

두 질문 뒤에 잠시 여백을 두고 중심 문구를 보여준다.

> **기억나지 않는 하루도, 다시 만날 수 있도록.**

**전달할 감정:** 바쁜 업무 속에서 기억과 자료를 다시 찾아야 하는 순간.

### 장면 2 — 파일이 날짜를 찾는다 · 4–9초

**역할:** 제품의 핵심 기능과 차별점을 한 장면으로 이해시킨다.

**화면**  
흩어져 있던 문서가 화면 중앙으로 모이고, 달력이 펼쳐진다. 문서들이 **수정일에 해당하는 날짜**로 이동하며 자리를 잡는다. 날짜 칸에는 HWP·PDF·XLS 등 파일 종류 배지가 나타난다.

**확정한 화면 문구**

> **따로 기록하지 않아도,**  
> **작업한 파일이 하루의 기록이 됩니다.**

**연출 주의:** 파일 자체가 이동하거나 정리되는 기능처럼 보이지 않게 한다. 파일 그래픽의 이동은 ‘수정일 기준으로 달력에 표시된다’는 개념을 시각화한 것이다.

### 장면 3 — 날짜에서 파일과 기억으로 · 9–15초

**역할:** 날짜별 파일을 통해 기억을 되찾고, 다시 챙길 일도 스스로 떠올리는 경험을 보여준다.

**화면**  
달력의 한 날짜가 확대되고, 그날의 파일 목록이 나타난다. 파일을 보는 사람이 “아, 이걸 검토했었지. 전달도 해야 했는데” 하고 스스로 떠올리는 상황을 시각적으로 전달한다. 이어 파일명 검색과 날짜 칸의 한 줄 메모를 짧게 보여준다. 가능하면 실제 앱 또는 기존 소개 페이지의 화면을 기반으로 기능별 상태를 표현한다.

**화면 문구 초안**

> 찾고 싶은 파일은 검색하고,  
> 기억할 일은 메모하고.

**보여줄 기능**

1. 날짜 선택 → 그날의 파일 목록 확인
2. 파일명 검색 → 관련 파일 찾기
3. 날짜별 한 줄 메모 → 필요한 맥락 남기기

### 장면 4 — 내 PC에 남는 기록 · 15–20초

**역할:** 업무 자료를 다룰 때 중요한 보관 방식과 선택권을 설명한다.

**화면**  
확대된 화면이 다시 달력 전체로 이어진다. 달력·색인·메모가 PC 안에 남는다는 의미를 간결하게 표현한다. AI 요약은 ‘선택 기능’으로 보조적으로 표시한다.

**화면 문구 초안**

> 내 업무 기록은 내 PC에.  
> AI 요약은 필요할 때만 선택.

**전달 기준:** 파일 색인과 메모는 로컬 저장이다. AI 요약은 기본적으로 꺼져 있으며 사용자가 켜고 요청할 때 파일명이 외부로 전송될 수 있다. “모든 기능이 항상 오프라인”이라고 단정하지 않는다.

### 장면 5 — 브랜드와 여운 · 20–22초

**역할:** 앞선 장면의 의미를 제품 이름과 연결한다.

**화면**  
달력에 정리된 기록이 차분하게 모이며 EveryDoing 이름이 나타난다. 마지막 문구를 읽을 시간을 둔다.

**마무리 문구 초안**

> **EveryDoing**  
> 내가 한 일을, 날짜로.

## 5. 기능 표현의 정확성

- 기준은 파일의 **수정일**이다. 파일을 처음 만든 날짜, 실제 작업 시간, 모든 변경 이력을 자동 기록한다고 표현하지 않는다.
- 달력은 선택한 경로와 확장자를 기준으로 스캔한 결과를 보여준다. PC의 모든 파일이나 과거의 모든 업무가 빠짐없이 복원된다고 약속하지 않는다.
- 날짜별 파일 목록은 업무를 **되짚는 단서**다. 보고서나 인수인계 문서를 자동 완성하는 기능처럼 표현하지 않는다.
- 놓친 후속 업무는 사용자가 파일을 보고 **스스로 떠올리는 것**이다. 앱이 미완료 업무를 자동으로 판단하거나 알려준다고 표현하지 않는다.
- 검색은 파일명 기준이며, 한 줄 메모는 사용자가 직접 입력한다.
- 로컬 보관 메시지와 AI 요약 메시지를 함께 제시할 때는, AI 기능이 선택적이며 외부 전송을 수반할 수 있다는 점이 흐려지지 않게 한다.
- 화면 속 파일명과 날짜가 예시라면 예시임을 알 수 있게 하고, 실제 사용자 업무 자료는 사용하지 않는다.

## 6. 확정된 방향과 남은 결정

**함께 정한 방향**

- 파일 찾기, 지난 작업 확인, 보고·성과 정리 등 여러 상황을 하나의 이야기로 묶는다.
- 문서로 일하지만 한 일을 별도로 기록하기는 부담스러운 실무자에게 말한다.
- 중심 문구는 “기억나지 않는 하루도, 다시 만날 수 있도록.”이다.
- 첫 질문은 “어제 뭐 했더라…?”, “지난주엔 뭐 했더라…?”다.
- 핵심 약속은 “따로 기록하지 않아도, 작업한 파일이 하루의 기록이 됩니다.”다.
- 차분하고 세련된 분위기 안에서 역동적인 움직임을 사용한다.
- 흩어진 파일이 달력의 날짜를 찾아가는 장면을 중심에 둔다.
- 검색·메모와 로컬 보관, 선택형 AI 요약을 이야기의 후반부에 연결한다.
- 기존 소개 페이지를 시각적 출발점으로 삼고 README에서 소개 영상을 볼 수 있게 한다.
