Features

필요한 것만.
빠르게.

복잡한 설정 없이 스캔 폴더만 지정하면 됩니다. 나머지는 EveryDoing이 합니다.

📅
수정일 기준 달력
파일 수정일을 읽어 월 달력에 자동 배치합니다. 어느 날 어떤 문서를 건드렸는지 한눈에 확인합니다.
⚡
NTFS MFT 직접 인덱싱
별도 프로그램 설치 없이, 켜자마자 인덱싱을 시작합니다. 실행 파일 하나면 끝입니다.
🔒
완전 로컬
색인·달력·메모·통계 모두 이 PC에서만 처리됩니다. 파일이나 사용 기록은 외부로 나가지 않습니다.
🗂파일 색인로컬
📝메모 저장로컬
📊월간 통계로컬
✨AI 총평선택 · 기본 꺼짐
🏷
파일 종류 배지
HWP·DOC·XLS·PPT·PDF를 색상 배지로 구분합니다. 어떤 종류의 작업을 했는지 즉시 파악.
HWP DOC XLS PPT PDF
✏️
한 줄 메모
날짜 칸 빈 곳을 클릭하면 바로 메모를 입력합니다. 로컬에 저장되고 언제든 수정합니다.
Privacy

끄면
외부 전송 0.

AI 총평은 선택 기능입니다. 꺼두면 이 앱은 내 파일과 기록을 외부로 전혀 보내지 않습니다. 켜더라도 파일명만, 매번 동의할 때만 전송합니다. (자동 업데이트 확인도 설정에서 끌 수 있습니다.)

Install

빌드하고
바로 씁니다.

관리자 터미널 하나면 됩니다.

⚙ 사전 요구사항

1
Windows 10 / 11 (x64)
2
Rust 1.77+ — rustup.rs
3
Visual Studio Build Tools + WebView2 (Tauri 2 요구사항)
4
관리자 권한 — MFT 원시 접근에 필요

🚀 개발 / 배포

# 저장소 클론
git clone https://github.com/hanjjaem/everydoing

# 개발 실행 (관리자 터미널)
cargo tauri dev

# 배포 빌드 (NSIS 설치본)
cargo tauri build
설정 파일: %APPDATA%\EveryDoing\config.json
