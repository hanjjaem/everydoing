# 최근 작업 타임라인 중심 재설계 (토스·애플 철학) — 설계 문서

작성일: 2026-06-25
대체: 이전 "Apple 테마" 작업(색·폰트 스타일링)은 표면에 그쳐, 정보구조·화면흐름을
다시 설계한다. 종이 톤·명조 마스트헤드·단일 강조색 비주얼은 계승.

## 목적과 설계 철학

이 앱의 주 사용 시나리오는 **"최근에 뭐 했는지 훑기"**. 그래서 화면을 이 하나에
최적화한다. 적용한 두 철학:
- **애플** — 콘텐츠가 주인공, UI는 양보(deference), 명료함. 빈 격자가 아니라
  *내가 한 일*이 화면의 주역이어야 한다.
- **토스** — 극단적 단순함, 한 화면 한 목적, 인지부하 최소화, 친절함, 한 흐름.

핵심 명제: **달력은 "지도", 타임라인은 "내용".** 사용자가 보고 싶은 건 내용이므로
타임라인이 주인공이 된다.

## 화면 레이아웃 (2단)

```
2026 / 6월 / 8일 기록 · 72개 문서        [검색] 설정 ☾   ← 마스트헤드
┌──────────────────────────┬───────────────────────────┐
│ 월 달력 (약 55%)          │ 최근 작업 타임라인 (약 45%) │
│ 요일헤더 + 날짜 + 개수배지 │ 날짜 그룹 역순 + 파일명 노출 │
│ (맥락·날짜 점프용)         │ (주역, 스크롤로 과거)       │
└──────────────────────────┴───────────────────────────┘
```

- 마스트헤드: 기존 에디토리얼 톤(작은 연도, 명조 월, "N일 기록 · M개 문서" 요약) 유지.
- 좌측 달력: 기존 월 격자 + 개수 배지. "어디에 일이 몰렸나"를 한눈에.
- 우측 타임라인: 열자마자 최근 작업이 **파일명으로 바로 읽힘**.

## 타임라인(주역) 상세

**구성 (콘텐츠 우선)**
- 날짜 그룹 헤더: `6월 23일 · 월`. 오늘은 `오늘 · 6월 25일`, 어제는 `어제 · 6월 24일`.
- 파일 행: 파일명이 또렷한 주역, 확장자·수정시각 등 메타는 흐린 부속.
  (수정시각이 데이터에 없으면 시각은 생략 — 파일명만.)
- 행 전체가 클릭 타깃(넓은 영역).
- 한 날짜 그룹은 역순(최근 날짜가 위), 그룹 내 파일은 이름순 등 일관 정렬.

**인터랙션 (점진적 공개)**
- 평소엔 파일명만. 행 hover 시 우측에 액션 노출: `열기 · 폴더 · 경로복사`.
- 행/파일명 클릭 = 기본 **파일 열기**(POST /api/open mode=file). 폴더·복사는 hover 액션.
- 기존 prompt() 방식 메뉴는 제거(투박함 — 철학 위배).

**스크롤**
- 최근부터, 아래로 과거. 전체 데이터는 메모리에 있어 즉시. 맨 위는 항상 최근.

**빈 상태 (가르치는 빈 화면)**
- 기록 없으면 "아직 기록이 없어요. 설정에서 작업 폴더를 추가해 보세요" + 설정 유도.

**검색 연동**
- 검색어 입력 시 타임라인·달력 배지가 함께 필터(기존 filterFiles 재사용).

## 달력 ↔ 타임라인 연동

**상태 = 두 값만**: `현재 월(cur)`, `선택된 날짜(selectedDate, 없을 수 있음)`.
달력·타임라인·요약 모두 이 두 값으로 그려진다.

- **기본**: 달력·타임라인 같은 달. 타임라인은 그 달 작업 최근순.
- **날짜/배지 클릭**: selectedDate 설정 → 타임라인이 그 날짜로 부드럽게 스크롤 +
  그룹 강조. 달력에서도 선택 날 표시. 같은 날 재클릭 또는 "전체 보기"로 해제.
- **월 이동(←/→)**: cur 변경 → 달력·타임라인·요약 함께 갱신. selectedDate 초기화.
- **오늘로 복귀**: 마스트헤드의 월(또는 오늘 버튼) 클릭 → 이번 달·오늘로.
- 모달·페이지 전환 없음. 같은 화면 안에서 시선만 이동.

## 비주얼·모션

**비주얼 원칙**
- 여백이 콘텐츠를 구분(타임라인은 카드로 감싸지 않음 — deference). 달력만 격자 유지.
- 위계는 크기·무게로: 파일명(진하게) > 날짜 헤더(중간) > 메타(흐림). 강조색은
  today·선택·hover에만 절제.
- 종이 톤 + 명조 마스트헤드 + 단일 강조색(버건디/다크는 테라코타) 계승. 다크 토글 유지.

**모션 (절제)**
- 날짜 클릭: 타임라인 부드러운 스크롤 + 그룹 배경 페이드 강조.
- 월 이동·검색: 타임라인 항목 가벼운 페이드인(transform/opacity만). 바운스 금지.

**피드백 (친절)**
- 파일 열기 시 잠깐 진행 표시. 실패 시 비난 없는 안내("파일을 찾을 수 없어요. 옮겨졌을 수 있어요").

## 기술 범위

- **변경**: `static/index.html`(2단 레이아웃 + 타임라인 마크업), `static/app.js`
  (타임라인 렌더·상태 두 값·연동·hover 액션·빈 상태).
- **서버 변경 없음** — 데이터는 기존 `/api/files`. 전부 클라이언트.
- **반응형**: 좁은 폭에서는 타임라인이 달력 아래로 내려가는 1단 세로 배치(단순 1단계).
- **검증**: 순수 함수(`filterFiles`, 날짜 그룹·라벨 포맷 함수)는 Node로, 레이아웃·모션·
  연동은 브라우저 수동. 기존 pytest 18개 회귀.

## 범위 밖 (YAGNI)

- 가상 스크롤(월 단위라 양 적음), 드래그, 키보드 단축키, 무한 로딩.
- 수정시각 표시는 데이터에 있을 때만(없으면 생략).
- 사이드바를 별도 팝업/모달로: 타임라인을 상시 노출로 대체하므로 불필요.
