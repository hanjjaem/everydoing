## 무엇을 합니까

업무 파일이 PC 어딘가에 있습니다. 언제 만들었는지 기억은 흐릿합니다.

EveryDoing은 스캔 폴더 안의 파일을 **파일 수정일 기준**으로 달력에 펼쳐 보여줍니다. "그날 어떤 문서를 건드렸는지"가 한눈에 들어옵니다. 검색·외부 앱·태그 작업 없이.

<br/>

### 주요 기능

| | |
|---|---|
| **달력 색인** | 수정일 기준, HWP·DOC·XLS·PPT·PDF를 브랜드색 배지로 날짜 칸에 표시 |
| **파일 드로어** | 날짜 클릭 → 우측 패널에 해당일 파일 목록 |
| **한 줄 메모** | 날짜 칸 빈 곳 클릭 → 인라인 편집, 로컬 저장 |
| **월간 요약** | 활동일·문서 수·최다 활동일·파일 유형 분포를 한 화면에 |
| **MFT 직접 인덱싱** | Everything 없이 NTFS MFT를 직접 순회, 관리자 권한만 필요 |
| **AI 총평 (선택)** | 기본 꺼짐. 켜면 그달 파일명으로 한 줄 총평. 끄면 외부 통신 0 |

<br/>

## 데이터 흐름

```
PC 내 파일
    │
    │  NTFS MFT 직접 순회 (관리자 권한)
    ▼
index.json ──── 달력 렌더링 ──── 화면
    │
    │  로컬에만 저장
    ▼
memos.json     %APPDATA%\EveryDoing\
config.json    스캔 경로, 확장자 설정
```

```
AI 총평 (기본 꺼짐)
    │
    │  사용자가 직접 켬 + 매 전송마다 confirm
    │  전송 대상: 파일명만 (내용 아님)
    ▼
OpenAI API  ←── 사용자 본인 API 키 (BYOK)
```

> 공공기관·폐쇄망 환경에서는 AI 요약을 끄면 외부 통신이 전혀 없습니다.

## 설치 / 빌드

**요구 사항**

- Windows 10 / 11 (x64)
- [Rust](https://rustup.rs) 1.77+
- [Tauri 2 사전 요구사항](https://tauri.app/start/prerequisites/) — Visual Studio Build Tools, WebView2

**개발 실행** (관리자 터미널)

```bash
cargo tauri dev
```

**배포 빌드** — NSIS 설치본, UAC 승격 포함

```bash
cargo tauri build
```

설정 파일 위치: `%APPDATA%\EveryDoing\config.json`
